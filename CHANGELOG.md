# Changes

The first line of each version is what Bloom shows when it offers the update.

## 0.3.2
- Update notifications: Bloom can tell you when a new version is out, and update itself in one tap. It asks first, and stays offline if you say no.

## 0.3.1
- Fit size: make a photo fit under 20, 50, 100, 200 or 500 KB, or your own limit and exact size, for exam, job and KYC forms.

## 0.3.0
- Bloom for Android: share any file to Bloom for the petal wheel. Works offline.

## 0.2.1
- Linux on ARM64 (Raspberry Pi and ARM PCs).

## 0.2.0
- First public release for Windows and Linux.
