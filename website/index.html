Features

One drag, the right wheel.

Bloom reads what you're dragging and only offers what fits it. Shift opens formats, Ctrl opens tools for that kind of file.

Privacy

Your files stay on your computer.

Online converters need a copy of your file. That puts private documents, photos and their hidden details on a server you don't control. Bloom does the work with tools that run on your machine: ffmpeg for video and audio, LibreOffice for documents, and built-in PDF and image libraries.

Uploading adds risk

Your file leaves your computer, so you have to trust how another service stores, processes and deletes it.

Bloom works locally

Conversions, tools and actions run on your own computer. It works offline, behind a firewall, and on files you'd never upload.

  1. Run Bloom-Setup.exe. It installs for your user only, no admin rights needed. If Windows warns about an unknown app, choose More info → Run anyway.
  2. Keep Start when I log in and Open in Bloom ticked.

Windows 10 and 11, 64-bit. ffmpeg comes built in. Install LibreOffice (free) to convert documents, spreadsheets and slides. On Windows 11, Open in Bloom sits under Show more options.

  1. Double-click the downloaded file and choose Install, or run the command below.
  2. Open Bloom from your apps. It starts by itself every time you log in.
